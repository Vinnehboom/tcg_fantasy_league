# simple-english

Write or rewrite technical text with ASD-STE100 Simplified Technical English — clear, unambiguous, free of AI slop.

## What it does

Applies the 53 rules of ASD-STE100 (aerospace/defense maintenance-documentation English): 20/25-word sentence limits, one word one meaning, simple verb forms, active voice, condition before command. Used for docs, READMEs, runbooks, error messages, release notes, incident reports, and API guides.

## How to invoke

Triggers on "STE", "Simplified Technical English", "ASD-STE100", "de-slop", "make this readable", "write for non-native readers", or a request for docs that translate well.
