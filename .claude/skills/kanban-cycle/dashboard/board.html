Cycle log

Each /kanban-cycle run writes what it found to this page: pull requests, dispatched agents, board counts, and one line in the cycle log. The page shows that record. It does not read GitHub or Notion by itself.

Prompts, answers, and removal requests that you type here wait in a queue. The next cycle for that project reads the queue, acts, and clears it. Nothing here starts a cycle.

A removal request never erases a Notion page. A decision moves to Superseded. A style rule is taken out of the guide, and the change log keeps the record.
